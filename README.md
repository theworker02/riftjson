# riftjson

Rift color json values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/riftjson/

## Install / run

```bash
git clone https://github.com/theworker02/riftjson.git
cd riftjson
node src/cli.js
node --test
```
